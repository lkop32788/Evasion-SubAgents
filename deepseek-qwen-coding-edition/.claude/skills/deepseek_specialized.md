# DeepSeek 专用技能

## 使用场景
- 需要 DeepSeek 模型执行复杂分析和分步推理
- 需要稳定的结构化输出（结论、依据、行动项）
- 需要在多约束条件下进行任务规划

## 执行原则
1. 明确输入边界与目标
2. 先给结论，再给依据
3. 输出统一为结构化格式
4. 对不确定内容明确标注假设

## 输出规范
- 结论
- 关键依据
- 风险与限制
- 下一步建议
